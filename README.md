# Frontend Mentor - Social Links Profile

This is my solution to the [Social links profile challenge](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ) on Frontend Mentor.

## Overview

### The challenge

The goal of this challenge was to build a social links profile that matches the provided design and is responsive across different screen sizes.

Users should be able to:

- View the profile on different screen sizes.
- See hover states for all interactive elements.
- See focus states when navigating with the keyboard.
- Access the different social profile links.

## What I learned

While building this project, I practiced:

- Structuring a page using semantic HTML.
- Using Flexbox to center and arrange content.
- Creating a responsive layout with `min-height`.
- Using CSS `margin: auto` to center elements.
- Styling links and making the entire link area clickable.
- Creating `:hover` states for interactive elements.
- Creating `:focus` states for keyboard accessibility.
- Using CSS pseudo-classes.
- Organizing styles using reusable class selectors.
